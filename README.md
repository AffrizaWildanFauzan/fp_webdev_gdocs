# 🏠 Real Estate Marketplace

Platform properti interaktif untuk mencari, menjual, dan menyewa properti dengan mudah.

## ✨ Fitur Utama

### 🏠 Property Management
- Daftar properti dengan grid/list view
- Filter dan search advanced
- Detail properti dengan gallery, map, dan virtual tour
- Wishlist dan compare properties

### 👤 Authentication & Authorization
- Register dan Login dengan JWT
- Role-based access (Admin, Agent, User)
- Profile management

### 📊 Agent Dashboard
- Statistik properti (total, views, inquiries)
- Grafik penjualan per bulan
- Manage properti (CRUD)
- Manage inquiries

### 🗺️ Interactive Maps
- Menampilkan properti dengan marker
- Cluster markers
- Popup info properti

### 🏦 Mortgage Calculator
- Simulasi KPR dengan hasil real-time
- Estimasi cicilan per bulan

### 📱 Responsive Design
- Mobile-first approach
- Dark/Light mode toggle
- Smooth animations dengan Framer Motion

## 🛠️ Teknologi

### Frontend
- React.js + Vite
- Tailwind CSS
- Framer Motion
- React Router DOM
- React Query
- Zustand
- Recharts
- Leaflet
- Socket.io Client

### Backend
- Node.js + Express.js
- MongoDB + Mongoose
- JWT Authentication
- Socket.io
- Cloudinary (image upload)
